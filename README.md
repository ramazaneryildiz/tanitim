# Ramazan Eryıldız

Kişisel tanıtım sayfası. GitHub Pages üzerinden yayınlanır.

## Dosyalar

- `index.html` — sayfadaki yazılar
- `styles.css` — görünüm
- `favicon.svg` — sekme simgesi

Fotoğraf veya sosyal medya paketi gelince dosyalar proje klasörüne konur. Sayfa buna göre güncellenir.

## Telefondan düzenlemek

1. [cursor.com/agents](https://cursor.com/agents) adresini aç.
2. `tanitim` reposunu seç.
3. Değişikliği yaz. Asistan bir birleştirme isteği açar.
4. İsteği birleştirince canlı site güncellenir.

Yazılar `index.html` içindedir. Ad, unvan, hakkımda, üç madde ve iletişim satırları oradan değişir.
